🛒 Amazon Clone – E-commerce Homepage

A modern, Amazon-inspired e-commerce homepage built to recreate the look and feel of Amazon's online shopping platform. The project features a clean user interface with product categories, promotional sections, and a responsive navigation layout.

🌐 Live Demo

"View Live Website" (https://amazon-project-lilac.vercel.app/)

📌 About the Project

This project is a frontend development practice project inspired by Amazon. It focuses on creating an attractive and user-friendly shopping homepage with an organized layout and familiar e-commerce design elements.

The homepage provides users with a shopping-style experience through different product categories, promotional banners, and navigation options.

✨ Features

- Amazon-inspired homepage design.
- Navigation bar with logo and shopping options.
- Product search bar.
- Delivery location section.
- Account and orders navigation.
- Shopping cart section.
- Promotional deals and offers.
- Gaming accessories category.
- Fashion and clothing category.
- Attractive product images and banners.
- Clean and user-friendly interface.

🖥️ Website Sections

1. Navigation Bar: Includes logo, delivery location, search bar, account options, orders, and cart.
2. Hero Section: Displays a promotional banner with a shopping message.
3. Top Deals: Highlights promotional offers.
4. Gaming Accessories: Displays headsets, keyboards, gaming mice, and gaming chairs.
5. Fashion Section: Showcases jeans, tops, dresses, and shoes.
